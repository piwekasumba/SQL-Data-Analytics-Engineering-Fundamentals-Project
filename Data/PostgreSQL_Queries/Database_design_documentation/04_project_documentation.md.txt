• Project Purpose

This project focuses on building structured relational database systems using SQL in a learning-focused environment. It demonstrates foundational skills in database design, data modelling, and query development using realistic business-style datasets.

---

• Future Improvements

As I continue developing this project, I aim to improve both structure and analytical depth through:

- Improving query performance through indexing concepts
- Exploring basic ETL-style data preparation using SQL
- Creating views to simplify repeated analysis queries
- Writing cleaner and more reusable SQL scripts
- Expanding analysis with additional datasets and scenarios

These improvements will help strengthen the project’s alignment with real-world data analysis and reporting workflows.
